Política de Privacidade

Última atualização: Setembro de 2026

A Sara Araújo Imóveis, inscrita sob o CRECI/DF 27053, valoriza a privacidade dos visitantes deste site e está comprometida com a proteção dos dados pessoais conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

1. Dados que coletamos

Ao visitar esta página, podemos coletar:

  • Dados de navegação: endereço IP, tipo de navegador, sistema operacional, páginas visitadas, tempo de permanência.
  • Dados de UTMs e parâmetros de campanha (fonte, meio, campanha) — identificam de onde você veio.
  • Dados voluntariamente fornecidos por você ao iniciar uma conversa pelo WhatsApp (nome, telefone, mensagem).

2. Como usamos os dados

Os dados coletados são utilizados para:

  • Responder às suas solicitações de informação sobre o imóvel anunciado.
  • Avaliar o desempenho das campanhas de anúncios (Meta Ads, Google Ads).
  • Cumprir obrigações legais e regulatórias do CRECI/DF.

3. Meta Pixel (Facebook Pixel)

Este site utiliza o Meta Pixel, ferramenta de análise da Meta Platforms, Inc., que coleta dados de navegação de forma anonimizada para mensurar a eficácia das campanhas publicitárias. Os dados são tratados conforme a Política de Dados da Meta disponível em facebook.com/privacy/policy.

4. Compartilhamento de dados

Não vendemos ou alugamos seus dados pessoais. Compartilhamos informações exclusivamente com prestadores de serviço essenciais (Meta, provedores de hospedagem) e quando exigido por lei.

5. Seus direitos como titular

Conforme a LGPD, você tem o direito de:

  • Confirmar a existência de tratamento de dados.
  • Solicitar acesso, correção ou eliminação dos seus dados.
  • Revogar consentimento a qualquer momento.

Para exercer qualquer desses direitos, entre em contato diretamente com a consultora responsável.

6. Retenção

Os dados de navegação são retidos pelo período necessário ao cumprimento das finalidades acima. Conversas de WhatsApp seguem a política da plataforma WhatsApp.
